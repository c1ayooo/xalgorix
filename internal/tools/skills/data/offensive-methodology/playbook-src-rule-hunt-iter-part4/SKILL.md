## 二、不干什么

| 条 | 规则 |
|----|------|
| 不进短表 | 没出洞的流水；FOFA 条数；某站今天挖了啥；纯登录墙过程；同皮再确认；只用一次的 path；未交报告的目标 host；完整 token / 密钥实值。中危打穿了也不进。虚标（打开 format「漏洞等级」对正文，一条都没中）当没高危，不进；不以标题写高危为准。无新认的通用枪（换 id、空密、omit、列表自增、每个 path 丢 `'`）不进。进短表必须先过门槛，再过三问。不进短表 ≠ 矩阵少测一类。登录 / 重置 / 改绑 / 换票仍按 `dig-scope` §4.2.2 测。 |
| 禁止 | 用总结冒充挖洞进度；写表超过半分钟还在磨字。短表写成日记、周报、某 host 档案。没含金量进表；高危就进表；库里没有就丢；库里已有还另开一行；有新差分却不补原行；补行时把认什么改成产品/path 点名；把算成写成过签/缺参/接口 200；太窄（同形态认不到）还硬补；当教材去同构写废报告（测可以）。生搬短表；表没有就不挖；把表当本站唯一清单。单站没中就删手法 / 把「没打穿」写成假点。为防臃肿删旧库、删仍能出高危的行、按日期拆一堆短表、每站通读整库。借「省 token / 只读节」少开该开的模块、少测一类。自己写下的高危报告还等用户说「放」才进表。用户丢来的已经看懂、值得补，还空等「放」才动文件。拿表打断一种子闭环。借「迭代」少挖、少搜、少类型。开新任务不写线程必读；spawn 交付停在「落报告」；子线程直接改短表；主控不收拟进行。把迭代理解成挡换站 / 等并完短表才走 `dig-scope` §4.3。为了短收拾已有知识库正文。把「没抽到执行类钥匙」读成本站永不测执行；把执行类例子当成白名单、清单外的执行面不挖；把 RCE 抬到整场换 id/改密前面当主业；认到执行类形态就开新种子 FOFA；把开模块理解成只测表上那一枪或改去打越狱；首页没扫到词就给 RCE 整段 N/A（清单/抓包/回包还没看）。 |
| 写不写 | 只认 `vuln-report-format.md`。本表不管 CORS / 发码 / 上传交不交报告，只说中危不进短表。短表和模块不定级、不另建建议等级表。细节一长写进对应旧模块，短表只留指针。 |


> 术语：`dig-scope` 指 `playbook-src-rule-dig-scope-workflow`。
